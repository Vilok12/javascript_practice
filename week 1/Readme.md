JavaScript Practice
This repository contains JavaScript practice programs organized week-wise to help beginners learn and improve their JavaScript programming skills. The programs cover basic to intermediate concepts with simple examples and problem-solving exercises.

The repository is designed for students and beginners who want hands-on practice with JavaScript fundamentals, logic building, and reusable programming concepts.

How to Run the Programs
Using Node.js
Install Node.js on your system.

Open the project folder in VS Code.

Open the terminal.

Run the required file using the command:

Bash

node filename.js
