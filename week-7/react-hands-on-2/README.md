Task Manager
Task Manager is a simple React application used to add, organize, and manage daily tasks efficiently. The project helps users keep track of tasks by allowing them to add tasks, set priorities, and monitor completed work.

This project is designed for practicing React concepts and building interactive frontend applications using modern web technologies.

Project Overview
The Task Manager application provides a clean and simple interface for managing daily activities. Users can create tasks, assign priorities, and view task statistics in an organized layout.

The project demonstrates component-based development and dynamic UI rendering using React.

Features
Add new tasks

Select task priority

View task list

Display total tasks

Display completed tasks

Responsive user interface

Simple and clean design

Dynamic task management

Users enter task details using input fields.

Tasks are stored and displayed dynamically using React state.

Users can:

Add tasks

Select task priority

Mark tasks as completed

Task statistics display:

Total number of tasks

Completed tasks
