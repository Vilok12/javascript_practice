Products Demo
Products Demo is a simple React application that displays product cards with images, prices, brands, and descriptions. The project is designed to practice React fundamentals and build a clean, responsive product showcase interface.

This application demonstrates how to create reusable components and dynamically display product data using React.

Project Overview
The Products Demo application provides a simple shopping-style interface where users can view product details in card format. The project focuses on frontend UI development and component-based architecture using React and Vite.

How the Project Works
Product data is stored in arrays or objects.

React components dynamically render product cards.

Each card displays:

Product Image

Brand Name

Product Description

Product Price

CSS is used for layout styling and responsiveness.

Vite provides fast project development and hot reload functionality.
