E-Commerce Website
This project is a simple and responsive E-Commerce web application developed using modern frontend technologies. The application provides a basic online shopping interface where users can browse products, view product details, and explore a clean user-friendly design.

The project is built for learning and practicing React concepts such as components, props, state management, and dynamic rendering.

Project Overview
The E-Commerce Website demonstrates how a frontend shopping application works by displaying products in an organized and responsive layout. It focuses on creating reusable React components and building an interactive user interface.

Features
Display product cards

Product images and descriptions

Product price details

Responsive user interface

Simple and clean design

Dynamic rendering using React

Installation and Setup
Clone the Repository
Bash

git clone <repository-url>
Navigate to Project Folder
Bash

cd E-Commerce-Website
Install Dependencies
Bash

npm install
Run the Development Server
Bash

npm run dev
After running the command, open the local server link shown in the terminal in your browser.

How the Project Works
Products are stored in arrays or data objects.

React components display the products dynamically.

Product cards contain:

Product Image

Product Name

Description

Price

CSS is used for styling and responsive layout.

The application updates automatically during development using Vite.
